# QuickGPT

An AI chat assistant with text and image generation, built with the MERN stack.

## Features

- User signup and login
- AI text chat
- AI image generation
- Community page to share generated images
- Credit system
- Dark and light mode
- Responsive design for mobile and desktop

## Tech Stack

- React, Tailwind CSS
- Node.js, Express.js
- MongoDB
- ImageKit, Gemini API
- Deployed on Vercel

## Run locally

```bash
# server
cd server
npm install
npm run server

# client
cd client
npm install
npm run dev
```

Create a `.env` file in `server` with your own keys:
`MONGODB_URI`, `JWT_SECRET`, `GEMINI_API_KEY`, `IMAGEKIT_PUBLIC_KEY`, `IMAGEKIT_PRIVATE_KEY`, `IMAGEKIT_URL_ENDPOINT`
